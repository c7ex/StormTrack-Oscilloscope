# Changelog

Все заметные изменения в этом проекте будут документироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [семантического версионирования](https://semver.org/spec/v2.0.0.html).

## [1.4.3] - 2026-08-23

### Added
- Защита от чтения пустых векторов при автоскейлинге.
- Выделен цикл рендеринга в отдельный файл.

## [1.4.2] - 2026-08-23

### Added
- Изменения при трекинге данных: теперь курсор скрыт при наведении на отслеживаемую точку.
- Добавлена настройка цвета фона графика и цвета фона окна.

## [1.4.1] - 2026-08-23

### Added
- Исправлено состояние графика, когда данные отсутствуют или есть одна точка данных
- Добавлено warning-сообщение о данных при попытке автоскейлинга
  - нет данных (отсутствуют валидные трейсы)
  - данные не валидны (диапазон значений не допустим для автоскейлинга)

## [1.4.0] - 2026-08-22

### Added
- Теперь не требуется дважды нажимать клавиши `F` и `A`.
- Конфигурация настроек FPS/AutoScale вынесена в файл `ConfigUI.hpp`
- По умолчанию стоит автоскейлинг по X оси.
- В настройках проекта добавлена многопоточная сборка.
- Поправлена конфигурация отступов графика внутри окна.
- Добавлена API функция: `bool StormTrack::RealtimeView(const double load_value, size_t trace_index)`. Можно не создавать вектор при дозаписи.

## [1.3.4] - 2026-06-01

### Added

## [1.3.0] - 2026-05-17

### Added
- Обновлен SDK.
- Обновлен README.
- Обновлен демонстрационный проект.
- Добавлен метод `FrameView` для потоковой замены данных с перемещением (move semantics).
- Добавлен метод `RealtimeView` для накопления данных в конец трейса без удаления истории.
- Единый метод `AddTrace` для создания трейсов (заменяет `AddStreamingTrace`).
- Добавлен структура `StormTrackInitParameters` для начальной настройки окна:
  - `window_size` — размер окна в пикселях (по умолчанию 800x600).
  - `visible_area_size` — размер видимой области по осям X и Y (по умолчанию 100x100).
  - `start_coordination` — начальное смещение координат (по умолчанию 0, 0).
- Конструктор `StormTrack(HINSTANCE, StormTrackInitParameters, const wchar_t*)` для создания окна с пользовательскими параметрами.
- Второй конструктор с параметрами по умолчанию для быстрого старта.

### Deprecated
- `StaticData` — используйте `JustView`.
- `AddStreamingTrace` — используйте `AddTrace`.
- `Streaming` — используйте `FrameView` или `RealtimeView`.

## [1.0.0] - 2026-05-08

### Added
- Первый публичный релиз StormTrack.
- Отображение нескольких графиков в одном окне.
- Потоковое обновление данных в реальном времени (стриминг).
- Поддержка статических данных с выборками до 1 миллиона точек и более.
- Масштабирование колёсиком мыши относительно курсора; раздельное масштабирование по X при зажатом Shift; быстрый зум с Ctrl.
- Панорамирование перетаскиванием левой кнопкой мыши.
- Автоматическая подстройка видимой области по оси X под все активные трейсы (клавиша A).
- Интерактивная легенда: скрытие/отображение трейсов кликом по цветному квадрату.
- Отслеживание ближайшей точки данных при наведении курсора с подсветкой и отображением координат.
- Адаптивная сетка с числовыми подписями, линии сетки с прозрачностью.
- Изменение размера области графика перетаскиванием границ рамки.
- Многопоточная архитектура: окно графика работает в отдельном потоке, не блокируя консоль.
- Полное отсутствие внешних зависимостей — только чистый WinAPI/GDI.
- Безопасное управление GDI-ресурсами через RAII (устранены утечки кистей, перьев, шрифтов, регионов).
- API переработано: класс `WindowObject` переименован в `StormTrack` с методами `StaticData`, `AddStreamingTrace`, `Streaming`.
- Отображение FPS в углу графика.
